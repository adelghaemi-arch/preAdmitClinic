# نبض کلینیک — React SPA (تمام‌کلاینت)

نسخه نمایشی بدون بک‌اند و بدون دیتابیس. همه داده‌ها Mock فارسی هستند و در `localStorage` مرورگر ذخیره می‌شوند.

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:5173` را باز کنید.

برای StackBlitz / CodeSandbox کافی است همین پوشه را باز کنید و همان دو دستور بالا را بزنید.

## ورود با OTP پنج‌رقمی

1. بروید به `/login`
2. یکی از شماره‌های «ورود سریع» را انتخاب کنید (یا شماره بیمار/ناظر معتبر وارد کنید)
3. کد ۵ رقمی در پنل پیامک شبیه‌سازی‌شده نمایش داده می‌شود
4. همان کد را وارد کنید

نمونه‌ها:

- بیمار: `09123458910` (مریم‌السادات تابش)
- ناظر سازمانی: `09123409876`

باز کردن `/` بدون ورود، حالت نمایشی با کاربر `maryam` و سوییچ نقش را فعال می‌کند.

## مسیرها

| مسیر | توضیح |
|------|--------|
| `/` | داشبورد و ماژول‌های کلینیک (`?view=` و `?patient=`) |
| `/login` | ورود OTP |
| `/patient?token=...` | کیوسک QR بیمار بدون لاگین |

## نقش ادمین پلتفرم

از سوییچ نقش، «ادمین پلتفرم» را انتخاب کنید. منوها جدا از ادمین کلینیک‌اند: داشبورد پلتفرم، کاربران (GPS + نشست‌ها)، بازبینی ضدتقلب (دوربین + چندسشنی)، نظارت فنی، تنظیمات پایه، یکپارچه‌سازی و ممیزی. این پنل تک‌مستأجر است و رجیستری چندکلینیک ندارد.

در «تنظیمات حساب» هر کاربر می‌تواند نشست‌های فعال دستگاه/سیستم را ببیند و قطع کند. اگر یک حساب ≥۲ نشست هم‌زمان داشته باشد، در ضدتقلب پلتفرم هشدار چندسشنی ساخته می‌شود.

هنگام روشن بودن دوربین پیش‌پذیرش، هر ۳ ثانیه یک فریم امنیتی + GPS ثبت می‌شود تا ادمین پلتفرم آن را با عکس آخر کاربر مقایسه کند.
