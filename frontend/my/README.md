# frontend

اپلیکیشن React نسخه نمایشی **نفس**.

مستندات اصلی پروژه در [`../README.md`](../README.md) است.

```bash
npm install
npm run dev
```

## news — ویترین عمومی (نمونهٔ طراحی)

سایت معرفی و اتاق خبر «نفس» به‌صورت ایستا و بدون بیلد در [`news/`](news/README.md) است:

```bash
cd news && node serve.mjs   # http://localhost:4321
```

محتوا در `news/content.json` و راهنمای کامل ویرایش در [`news/README.md`](news/README.md).
