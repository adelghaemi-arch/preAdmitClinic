# شرط نمایش و مخاطب پرسشنامه پیش‌پذیرش

این سند **ماتریس ایده‌آل** شرط نمایش سوالات را توصیف می‌کند: کاربر نباید سوال نامرتبط ببیند، و اگر بعد از فیلتر هیچ سوالی در یک بخش نماند، آن بخش از استپر حذف می‌شود.

فایل اکسل هم‌تراز با کاتالوگ:

- [`شرط-نمایش-مخاطب-پرسشنامه.xlsx`](./شرط-نمایش-مخاطب-پرسشنامه.xlsx)

بازتولید اکسل از روی seed نویسنده:

```bash
python scripts/export_visibility_matrix.py
```

## منبع حقیقت و مسیر runtime

| لایه | نقش |
|------|-----|
| `frontend/src/lib/form-catalog.seed.json` | کاتالوگ نویسنده (schemaVersion 2) — `cancer_screening_male_v02` / `cancer_screening_female_v02` |
| `backend/.../SeedData/form-catalog.seed.json` | نسخهٔ embed برای seed API (هم‌محتوا با فرانت) |
| `SeedAsync` → `ImportPackageAsync` | در استارت API دو فرم CA را Published می‌کارد؛ `PREADMIT_V1` آرشیو/غیرفعال |
| `FormAudienceEvaluator` | بک‌اند: قوانین `{field,op,value}` + مخاطب `gender` با `"همه"` و `ageMin`/`ageMax` |
| `form-engine.ts` | فرانت بیمار: همان مدل قوانین + حذف بخش خالی |
| `GET /api/forms/structures` | hydrate ادمین/مالک از API (نه mock خالی) |
| `GET/POST /api/forms/package` و `package.xlsx` | export/import بسته برای Admin/Platform |

### Import / Export ادمین

در `AdminFormsBuilder`:

- خروجی / ورود **JSON** (بسته کامل schemaVersion 2)
- خروجی / ورود **Excel** (ماتریس + شیت‌های Forms/Sections/Items؛ import همان مسیر `ImportPackageAsync`)

اعتبارسنجی: کد یکتا، gender مخاطب، قوانین visibility شناخته‌شده؛ خطا با پیام فارسی.

## قواعد مخاطب

| دسته | شرط فنی | کاربرد |
|---|---|---|
| فرم فقط ≥ ۱۸ | `targetAudience.ageMin = 18` | هر دو فرم مرد/زن؛ زیر ۱۸ فرم دریافت نمی‌کنند |
| متأهل / ازدواج‌کرده | `maritalStatus` ∈ {متأهل، ازدواج‌کرده} | باروری، علائم جنسی، سابقه HPV، پاپ/HPV |
| سن ≥ ۵۰ | `age` ≥ ۵۰ | یائسگی، غربالگری پستان/روده/پروستات/ریه و … |
| همه | بدون `visibilityRules` | واکسن HPV و سایر سوالات (پس از عبور از سن فرم) |
| فقط مجرد | `maritalStatus` ∈ {مجرد} | قابلیت ادمین؛ در کاتالوگ فعلی آیتمی نداریم |

وضعیت تاهل از `Patient.MaritalStatus` یا پاسخ فیلد پایه `*_BASE_maritalStatus` خوانده می‌شود؛ سن از پروفایل بیمار.

### اطفال (دختر / پسر)

فرم جداگانه اطفال نداریم. هر دو پرسشنامه سرطان با `ageMin = 18` فقط به بزرگسالان assign می‌شوند. اگر سن بیمار کمتر از حداقل باشد، پیام: «پرسشنامه پیش‌پذیرش سرطان برای افراد … سال به بالا است.»

## رفتار بخش‌ها (دسته‌ها)

بخش‌ها معمولاً ترکیبی از سوالات عمومی و مشروط‌اند و به‌صورت کامل «فقط متأهل» یا «فقط ≥۵۰» برچسب نمی‌خورند.

در UI بیمار (`PreAdmitFormRenderer`):

1. فقط سوالهای `isItemVisible` رندر می‌شوند.
2. با `visibleSections`، بخشی که هیچ سوال قابل‌نمایش (غیر امضا) ندارد از استپر حذف می‌شود.
3. فاز غربالگری اگر خالی باشد رد می‌شود و مستقیم به مدارک می‌رود.
4. `resolveFormForPatient` جنسیت و `ageMin`/`ageMax` فرم را اعمال می‌کند.
5. سن برای visibility از **پاسخ تولد فرم** → `patient.birthDate` → `patient.age` گرفته می‌شود؛ اگر فقط `age` کهنه باشد و تولد ≥۵۰ باشد، سوالات غربالگری سن‌دار باید دیده شوند.

## فایل‌های مرتبط

- کاتالوگ نویسنده: `frontend/src/lib/form-catalog.seed.json`

- موتور فرانت: `frontend/src/lib/form-engine.ts`
