# News — ایندکس

ویترین عمومی «نفس» در این موج به‌صورت **نمونهٔ طراحی قابل کلیک** در [`frontend/news`](../../frontend/news) ساخته شد: یک سایت چندصفحه‌ای ایستا (بدون بیلد) برای سه مخاطب بیمارستان/کلینیک، بیمار و شریک، به‌همراه اتاق خبر.

| موضوع | مرجع |
|-------|------|
| اجرا، ساختار فایل، ویرایش محتوا | [`frontend/news/README.md`](../../frontend/news/README.md) |
| اسکلت دیپلوی ایستا | [`server/news`](../../server/news) — nginx، compose نمونه |
| دادهٔ پایدار (رزرو) | `server/persist/news-data` |
| راهنمای انتشار | [`../shared/server-deploy.md`](../shared/server-deploy.md) |

## تصمیم‌های محتوایی این نمونه

- **سه مخاطب، سه صفحه:** صفحهٔ مراکز درمانی روی «درد پذیرش و مدل استقرار»، صفحهٔ بیماران روی «چه داده‌ای، چرا، چه کسی می‌بیند»، و صفحهٔ مشارکت روی «دیوار شیشه‌ای» و ماشین‌حساب سهم.
- **عدد بدون برچسب نمی‌گذاریم:** آمار و نقل‌قول‌ها با نشان «نمونه» منتشر شده‌اند؛ جایگزینی با داده واقعی فقط بعد از پایلوت.
- **مرز محصول روشن است:** نفس لایهٔ ورودی پیش از پذیرش است، نه جایگزین HIS یا پروندهٔ رسمی.
- **راه‌های تماس و فرم‌ها** فعلاً نمایشی‌اند؛ اتصال به API در موج بعد.
- **محتوای تفکیک‌شده:** متن‌ها در ۹ فایل موضوعی (`content/site.json`، `home.json`، `hospitals.json`، `partners.json`، `news.json`، `voices.json`، `faq.json`، `about.json`، `contact.json`) هستند تا هر تغییر سطح اثر کوچکی داشته باشد؛ `node check.mjs` پیش از کامیت آن را بازبینی می‌کند.

## وضعیت

| قلم | وضعیت |
|-----|--------|
| نمونهٔ طراحی ۹ صفحه‌ای | آمادهٔ بازبینی |
| محتوای فارسی و اعداد فارسی | آماده (۹ فایل موضوعی در `content/`) |
| ابزار بازبینی و ری‌لود زنده | آماده (`check.mjs` + `serve.mjs`) |
| فرم‌ها و اتصال سرور | نمایشی — بدون ارسال |
| بازبینی حقوقی حریم خصوصی و شرایط پایلوت | انجام نشده |
