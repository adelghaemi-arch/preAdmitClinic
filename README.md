# نبض کلینیک

نسخه نمایشی تمام‌کلاینت برای پیش‌پذیرش، جریان کلینیک و همراهی سلامتجو — بدون بک‌اند و بدون دیتابیس سروری.

داده‌ها Mock فارسی‌اند و در `localStorage` مرورگر ذخیره می‌شوند. مناسب دمو محصول، بازبینی UX و ارائه به ذی‌نفعان.

---

## قابلیت‌ها

| حوزه | خلاصه |
|------|--------|
| **پیش‌پذیرش** | پرسشنامه ساختاریافته، آپلود مدارک، ثبت عکس و GPS |
| **جریان کلینیک** | پذیرش، صف‌ها، اتاق‌ها، اعلان‌ها و مسیر درمان |
| **پرونده الکترونیک** | ویزیت، تشخیص، پاراکلینیک و گزارش قابل چاپ |
| **همراه سلامتجو** | دسترسی محدود، نقشه مسیر و پیگیری وضعیت |
| **قرارداد سازمانی** | پکیج‌ها، سقف نوبت، قیف پیش‌ثبت‌نام و پنل ناظر |
| **ادمین پلتفرم** | کاربران، نشست‌ها، ضدتقلب، سلامت فنی و ممیزی |

---

## نقش‌ها

| نقش | کاربرد |
|-----|--------|
| سلامتجو | داشبورد شخصی، پرسشنامه، نقشه راه و گزارش |
| همراه سلامتجو | پیگیری در محدودهٔ اجازهٔ سلامتجو |
| پذیرش و هماهنگی | پذیرش، صف و جریان زنده |
| پزشک متخصص | لیست انتظار، معاینه، تشخیص و نسخه |
| کارشناس پاراکلینیک | صف تشخیصی و نتایج |
| ادمین کلینیک | قراردادها، قیف ثبت‌نام و تنظیمات |
| ادمین پلتفرم | نظارت سیستمی و ضدتقلب |
| ناظر سازمان | رصد کارکنان طرف قرارداد |

تغییر نقش از سوییچ نقش، فقط فضای کاری را عوض می‌کند؛ حساب کاربری تغییر نمی‌کند.

## شروع سریع

پیش‌نیاز: Node.js ۱۸ یا بالاتر.

```bash
cd frontend
npm install
npm run dev
```

سپس [http://localhost:5173](http://localhost:5173) را باز کنید.

| دستور | توضیح |
|-------|--------|
| `npm run dev` | سرور توسعه |
| `npm run build` | بیلد تولید |
| `npm run preview` | پیش‌نمایش بیلد |
| `npm run typecheck` | بررسی TypeScript |

باز کردن `/` بدون ورود، حالت نمایشی با کاربر نمونه و سوییچ نقش را فعال می‌کند.

---

## ورود (OTP پنج‌رقمی)

1. به `/login` بروید.
2. یکی از شماره‌های «ورود سریع» را انتخاب کنید، یا شمارهٔ معتبر وارد کنید.
3. کد ۵ رقمی در پنل پیامک شبیه‌سازی‌شده نمایش داده می‌شود.
4. همان کد را وارد کنید.

نمونه‌ها:

| نقش | شماره |
|-----|--------|
| سلامتجو (مریم‌السادات تابش) | `09123458910` |
| ناظر سازمانی | `09123409876` |

## مسیرها

| مسیر | توضیح |
|------|--------|
| `/` | داشبورد و ماژول‌ها (`?view=` و `?patient=`) |
| `/login` | ورود با OTP |
| `/patient?token=...` | کیوسک QR بیمار، بدون لاگین |

---

## نکات نمایشی

- همهٔ داده در مرورگر است؛ پاک کردن `localStorage` دمو را به حالت اولیه برمی‌گرداند.
- پنل ادمین پلتفرم تک‌مستأجر است و رجیستری چندکلینیک ندارد.
- هنگام روشن بودن دوربین پیش‌پذیرش، فریم امنیتی و GPS برای بازبینی ضدتقلب ثبت می‌شود.
- اسناد خام پرسشنامه و کدینگ در `docs/` و اسکریپت‌های تولید در `scripts/` قرار دارند.
